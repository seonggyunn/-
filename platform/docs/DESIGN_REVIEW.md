# 홈페이지 가독성·디자인 검토안

기존 사업 재설계 브랜치에 시각 개선을 추가했다. 운영 배포는 하지 않는다.

## 방향

크림색 바탕/짙은 초록/작은 테라코타 포인트로 동네 식당과 1인 서비스에 맞춘 차분한 인상.
사진이나 실제 후기 없이도 결과물을 이해하도록 가상 ‘매장 개선 노트’를 첫 화면에 배치한다.
가상의 원고·예시 표시는 유지하고 실제 매장 성과로 오해할 만한 통계/사진은 만들지 않는다.

## 읽기 순서

대상 고객 → 한 문장 핵심 제안 → 무료 진단 버튼 → 결과물 형식 → 무료/초기/월간 차이 → 적합 고객/운영자 → FAQ → 신청.
첫 화면 주 행동은 무료 진단 하나로 통일하고, 상세 범위는 서비스·요금·작업 방식 페이지로 연결한다.
홈에는 축약형 패키지를 쓰되 무료/유료 경계와 별도 견적을 유지한다. 전체 범위는 기존 상세 페이지에 있다.

공개 레이아웃을 `.public-site`로 감싸 색상·글자·카드·버튼·폼 스타일을 격리했다.
`src/app/public.css`는 공개 페이지에만 적용한다. 관리자·메일·API·DB 로직 변경 없음.
`src/components/Public.tsx`의 Home을 분리하고 첫 화면·샘플·요약 카드·FAQ 구성을 개선했다.
`src/app/layout.tsx`에서 스타일을 불러온다. 외부 폰트/이미지 요청이나 신규 의존성을 추가하지 않았다.
본문 바로가기와 키보드 포커스, 충분한 버튼 크기, 모바일 줄바꿈/독립 표 스크롤을 적용했다.

## 검증

타입/린트/기본28개 테스트 통과(별도 PostgreSQL 하니스1개 기본 실행 skip), 빌드 성공.
실제 Chromium 공개10경로/360px 및390px 모바일 넘침/신청 저장/로그인/진단/비공개 PDF 다운로드/JS오류0 확인.
추가로 첫 화면과 신청 화면을 실제 브라우저에서 촬영하고 시각 검토했다. 실제 접수/메일 발송은 추가 실행하지 않았다.
스크린샷 기준 홈페이지 높이: 데스크톱5330→4246px, 모바일7579→6039px(약20% 감소).
변환율 향상은 아직 확인하지 않았다. 실제 사용자 이해도·신청 전환·무료 서버 첫 접속 지연은 운영 적용 후 별도 확인한다.
기존 동적 로컬 파일 경로의 빌드 tracing 경고는 그대로이며 이번 디자인 작업에서 저장 로직을 수정하지 않았다.
