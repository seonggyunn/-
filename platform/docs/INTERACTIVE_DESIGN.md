# 공개 홈페이지 인터랙션 개선 — 2026-10-30

사용자가 제공한 스마트플레이스 참고 화면의 밝은 바탕, 넓은 여백, 안내 카드, 메뉴와 FAQ 구성을 참고했다. 한칸데이터의 브랜드와 서비스 범위에 맞춰 독자적인 문구·일러스트·레이아웃으로 구현했다.

## 바뀐 화면

- 첫 화면: ‘혹시, 우리 가게의 매력이 온라인에서는 잘 안 보이나요?’와 무료 진단 신청 버튼. 무료 범위(매장 1곳·개선 방향 최대 3개)도 함께 표시.
- 소개·메뉴/사진·방문 안내 고민을 다루는 3개 슬라이드. 화살표와 선택 버튼으로 전환하며 자동 재생하지 않음.
- 직접 제작한 SVG 가상 매장 화면과 고민별 확인 카드. 실제 고객·네이버 공식 화면·성과로 표시하지 않음.
- 상단 서비스/예시/이용 안내 펼침 메뉴: 데스크톱 마우스, 클릭, 키보드 지원. 모바일은 메뉴 버튼과 하위 메뉴 터치로 이동.
- 서비스 바로가기 5개, 카드와 버튼의 반응, 스크롤 진입 애니메이션.
- FAQ 분류(전체/무료 진단/작업과 자료/비용과 운영)와 답변 펼치기.
- 하단 빠른 안내 메뉴: 무료 진단/개선 예시/FAQ 연결. 신청 페이지에서는 표시하지 않음.
- Esc·바깥 클릭·포커스 이탈 시 메뉴 닫기, 감춰진 메뉴의 포커스 차단, 모션 감소 설정 대응.

## 범위

공개 홈페이지 디자인과 화면 인터랙션만 수정했다. 상품 범위, 유료 가격, API, DB 스키마, 인증·메일·저장소·관리자 기능은 변경하지 않았다. 새 패키지나 외부 이미지/폰트 요청을 추가하지 않았다.

## 검증

- typecheck / lint / build 통과.
- 단위·서비스 테스트 28개 통과. PostgreSQL 별도 실행 테스트는 이번 UI 변경에서 실행하지 않음.
- E2E: 공개 페이지 10개, 메뉴 hover/키보드/Esc, 슬라이드 순환, FAQ 분류·답변, 모션 감소, 모바일 메뉴 이동 통과.
- 기존 신청 필수 항목 저장, 관리자 로그인, 진단 기록·보고서 생성·인증 PDF 다운로드, 익명 차단 통과. 테스트 데이터는 격리 로컬 DB에만 생성.
- 추가 브라우저 검사: 320/360/390/768/1024/1440px에서 3개 슬라이드 가로 넘침 없음, 실제 터치 환경 메뉴와 빠른 안내 이동, JS 비활성화 상태 첫 화면·주요 신청 링크 표시.
- 기존 서버 파일 추적 빌드 경고 2건은 유지되며, 배포 결과물에 .data/.env 파일이 포함되지 않음을 검사.
