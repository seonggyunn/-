# 한칸데이터: 식당 온라인 개선 상품 검토안

2026-10-30 작성. 사업·시간·가격은 검증 가설이며 실제 시장조사·유료 계약·수익 실적이 아니다.
이번 변경은 검토 브랜치에만 작성한다. 운영 브랜치 병합·실서비스 배포·외부 발송·유료 가입·고객정보 수정은 포함하지 않는다.

## 한 문장과 첫 고객

**동네 개인 식당의 실제 강점을 인터뷰와 유사 매장 비교로 확인하고, 네이버 소개·메뉴·사진·이용 안내를 정리해 승인된 적용과 재확인을 돕는다.**

생활권에서 직접 대화하기 쉬운 영업 중인 개인 식당을 우선한다. 메뉴/사용 가능한 사진을 제공하고 원고 확인·권한 협의에 참여할 수 있는 매장이 대상이다. 네이버를 기본 채널로 한정한다.

구매 이유는 사장님이 못하는 클릭을 대신하는 것이 아니라, 무엇을 보여줄지 결정하는 시간·원고 정리·자료 선정·실행 확인을 맡기는 데 있다. 그러나 이 수요는 미검증이다. 단순 입력만 원하거나 자료가 없고 확인 시간을 낼 수 없는 고객에게는 적합하지 않을 수 있다.

## 기존 방향과 차이

| 영역 | 기존 | 이번 검토안 |
|---|---|---|
| 핵심 가치 | 플랫폼 기본정보 불일치 수정 | 강점·방문 판단 정보 정리와 적용 지원 |
| 고객/채널 | 다양한 소상공인·네이버/구글/웹 | 동네 개인 식당·네이버 우선 |
| 무료 | 기본정보 비교 | 공개 페이지의 개선 방향 최대 3개 |
| 초기 개선 | 항목별 입력·수정 | 인터뷰·비교·원고·메뉴·제공 사진·이용 안내 |
| 브랜드 | 외부·내부 한칸 운영실 | 외부 한칸데이터, 내부 한칸 운영실 |
| 신청 | 업종/담당자/서비스 선택 필수 | 매장 식별/이메일/고민 필수, 담당자와 채널 선택 |

기존 파일·기능 설명은 실제 코드와 일치했다. 다만 초기 문서 README의 ‘도메인/메일 미연결’ 설명은 사용자 확인된 운영 현황과 달라 갱신했다. Google/Naver API, 정기결제, 자동 경쟁 수집은 코드상 미제공이다. 기존 개인정보 안내는 새 수집 항목과 맞지 않아 수정했다.

## 상품 경계

### 무료 간단 진단

매장 1곳의 네이버 공개 페이지에서 핵심 개선 방향 최대 3개. 불명확하거나 접근 불가인 항목은 확인 필요로 남긴다. 내부 확인 10~15분, 회신·기록 포함 총 15~25분을 가정한다. 25분 이상이 필요하면 추가 자료를 요청하거나 유료 범위로 분리한다. 상세 비교 조사, 완성 소개문, 사진 작업, 계정 적용은 제외한다.

### 초기 개선 — 견적에 복사할 기본 범위

- 매장 1곳/네이버 1채널, 인터뷰 20~30분.
- 동일 상권·유사 업종·비슷한 가격대의 공개 매장 3곳. 선정 이유·URL·확인일 기록.
- 개선 과제 3~5개, 소개문 1안, 핵심 메뉴 최대 5개(이름·가격·구성·특징).
- 사용권 있는 고객 사진 최대 10장: 선정, 기본 밝기/크롭, 활용 제안. 전문 촬영·합성·고급 보정·영상 제외.
- 해당하는 주차·휴무·포장·예약 등 안내. 확인되지 않은 편의시설/주장 임의 작성 금지.
- 묶어서 받는 고객 피드백 1회. 추가 메뉴·사진·방향 전환·추가 라운드는 새 범위.
- 견적에 지정한 항목의 적용 또는 고객 직접 수정 지원. 권한/대행 가능 여부는 플랫폼별 확인.
- 전후 기록, 적용 완료·대기·불가 구분, 이후 1회 재확인. 첫 2곳은 예컨대 적용 후 7~14일을 협의하되 심사 통과/완료일 보장 금지.
- 자료 준비일·견적/동의 시점에 납기를 별도 합의. 1인 운영 감당 범위를 넘는 일정 확약 금지.

**단순화 이유:** 참고 매장 2곳까지 기본 포함하면 비교가 5곳으로 커진다. 초기에 3곳으로 제한하고, 비교 기준과 근거를 깊게 기록한다. 추가 참고 2곳은 별도 협의한다. 사진 간단 보정을 밝기/크롭으로 좁혀 촬영·상세 디자인과 경계를 정했다. 피드백은 묶어서 1회로 제한한다.

### 월간 운영 — 초기 개선 후 실제 반복 수요가 있을 때

월 1회 계획, 네이버 소식 콘텐츠 2건, 메뉴·사진 변경 요청 월 1회 취합, 공식 권한/고객 제공 자료로 확인 가능한 통계 요약과 다음 작업 제안. 건당 글자수·소재 수·변경 항목 수·피드백·취합 마감일은 계약에서 정한다. 전문 촬영·영상·광고비·광고 운영·상시 응대·무제한 변경 제외. 통계 미확보 시 미확보로 기록한다. 자동 게시·통계 연동·정기결제 없음.

## 내부 가격 가설과 시간 분석 — 공개 확정 판매가 아님

| 상품 | 가격 가설 | 예상 투입 | 단순 매출/작업시간 |
|---|---|---|---|
| 무료 간단 진단 | 0원 | 15~25분(확인 10~15분 포함) | 유료 전환과 무관하게 소요 시간 기록 |
| 초기 개선 | 총액 165,000~220,000원 가설 | 5~7시간 | 약 23,600~44,000원/시간 |
| 월간 운영 | 월 총액 220,000원 가설 | 월 3~5시간 | 약 44,000~73,300원/시간 |

위 값은 매출을 시간으로 나눈 값으로 순수익/시급이 아니다. 세금·수수료·도구 비용·이동·영업·비가동 시간은 반영하지 않았다. 최종 세무/총액 표기는 운영자 상황 확인 후 견적에서 확정한다. PDF·엑셀 서비스의 9만 원과 무관하다.

초기 개선 예산: 인터뷰/접수 0.5~0.75h + 공개 비교 0.75~1h + 소개/메뉴/안내 1~1.25h + 사진 0.5~0.75h + 피드백 0.5~0.75h + 적용지원 0.75~1h + 보고/재확인 0.5~0.75h ≈ 4.5~6.25h, 예비를 포함해 5~7h 가설.
권한/자료 지연, 장시간 원격 지원, 추가 수정은 8~10h 이상 위험. 8시간 초과라면 165,000원은 시간당 매출 약20,600원 이하이므로 범위 축소/가격 재설계가 필요하다. 실제 2곳의 시간 기록으로 판단한다.

월간 운영은 콘텐츠 소재가 정시에 제공된다는 가정이다. 사진을 매번 구하거나 현장 방문이 필요하면 3~5h 가정이 무너진다. 실제 반복 수요 없이 선판매하지 않는다.

## 시범 매장 2곳 — 비공개 검증 계획, 공개 모집 아님

- 2곳에 한해 무료 초기 개선을 제안하는 방안은 검토 중이며 실행하지 않았다.
- 대상: 위 고객조건, 인터뷰·자료·승인 참여 가능, 현재 작업 중복 여부 확인.
- 공개 모집을 하려면 실제 시작/종료 날짜·지역·선정 기준·개별 안내 기한·범위·종료 조건을 운영자가 확정해야 한다. 날짜를 임의로 만들거나 남은 자리 카운터를 게시하지 않는다.
- 무료라도 작업 범위·승인·중단·개인자료 보관을 문서로 합의한다. 긍정 후기·사례 공개·월간 계약·유료 전환은 조건으로 삼지 않는다.
- 사례 공개는 별도 선택 동의로 받는다. 미동의해도 작업에 불이익 없음.

## 실제 2곳에서 기록할 검증표

| 가설 | 기록할 증거 | 다음 결정 |
|---|---|---|
| 입력이 아닌 정리/적용 지원에 가치가 있다 | 인터뷰에서 가장 원하는 결과, 유료 견적에 대한 자발적 반응 | 가치 설명·대상 업종 유지/수정 |
| 3곳 비교가 충분하다 | 3~5개 제안 중 고객 수락/거절과 이유 | 비교 기준 조정, 추가 조사 기본 포함 여부 |
| 자료를 확보할 수 있다 | 자료 요청~수령 시간, 사진 사용권, 메뉴 사실 확인 횟수 | 자료 요건과 신청 전 안내 보완 |
| 5~7시간 안에 끝낼 수 있다 | 단계별 시작/종료, 이동/연락/재작업 시간 | 범위 축소 또는 가격 재산정 |
| 실제 적용 지원이 가능하다 | 공식 권한 확인, 적용/대기/불가 항목과 사유 | 플랫폼별 직접 지원 범위 변경 |
| 개선 원고를 고객이 활용한다 | 원고 승인·적용·재확인 결과 | 납품물/원고 구조 수정 |
| 반복 수요가 있다 | 월간에 맡기고 싶은 구체적 업무와 빈도 | 월간 상담 여부, 불필요한 고객에게 권하지 않음 |

납품 성과(작성/정리/적용 건수), 관찰 지표(권한으로 확인한 조회/통화/예약), 미확인 결과(방문/매출/수익), 외부 변수(광고/행사/휴무/계절)를 별도 기록한다. 2곳으로 효과의 통계적 검증이나 인과관계를 주장할 수 없다.

## 운영·관리자 재사용

기존 신청→진단→제안→승인→수동 실행→재확인→보고서를 재사용한다. 진단 항목명에 [공개 관찰]/[고객 확인]/[개선 가설]을 적고 실제 근거 URL/시각을 기록한다. 확인 사실만 VERIFIED, 고객 확인 필요는 CUSTOMER_CONFIRMATION_REQUIRED, 접근 불가는 UNAVAILABLE로 남긴다. 가설을 VERIFIED로 표시하지 않는다. 변경 제안에는 승인 대상 원고와 사유를 적는다. 적용 기록은 실제 작업 후에만 남긴다. 새 CRM/크롤러/큐/결제 시스템을 추가하지 않았다.

기존 시스템은 비교매장 전용 엔터티·통계 이력·사진 편집 도구를 갖추지 않았다. 비교표/시간표는 수동 문서와 비공개 증빙으로 운영한다. 승인 증빙·작업 기록을 실제 고객으로 검증하는 것은 별도 단계다.

## 확장 순서 — 이번 구현에서 제외

초기 개선 반복 납품 → 반복 수요 고객의 월간 운영 → 소재 확보 고객의 인스타 → 필요 고객의 한 페이지 사이트 → 업무 표준화 후 자동화.
브랜드는 외부 한칸데이터, 관리자 한칸 운영실. 새 도메인/유료 도구/로고 구매 없음.
