## 첫 상담과 납품

1. 매장과 고민을 식별하고 무료 최대3개 방향을 기록한다. 무료 작업 시간 목표는 공개 확인10~15분, 회신/기록 포함15~25분이다.
2. 유료 또는 별도 시범 제안을 원하는 경우 인터뷰/자료/권한을 확인한다. 무료 시범2곳은 검토안이며 아직 공개 모집하지 않는다.
3. 비교매장3곳의 URL/확인일/선정 이유와 관찰/고객 확인/가설을 구분한다.
4. 원고·메뉴·사진·이용 안내를 만들고 내용 피드백을 한 번에 받는다.
5. 플랫폼별 공식 권한·변경별 승인 확인 후 적용하거나 직접 수정을 지원한다. 비밀번호/인증코드를 받거나 소유권 이전을 기본 절차로 삼지 않는다.
6. 적용·반영 대기·불가를 나눠 전후 기록과 1회 재확인을 전달한다.
7. 작업별 시간·수락 이유·반복 요청을 기록해 다음 가격과 범위를 조정한다. 테스트 신청·계약 금액을 실제 고객 실적·입금액으로 집계하지 않는다.
