# 학과 공싸움 테스트판

주소: `/campus-battle`. 기존 사업 홈페이지와 분리한 신규 공개 게임 페이지.

## 플레이

- 주요 학과명 133개, 계열별 선택, 검색 입력 목록, 직접 입력(최대 30자), 랜덤 두 학과.
- 두 공은 벽에 튕기고 2초마다 서로 돌진. 충돌하면 무작위 한쪽이 피해를 입음. 치명타 확률 20%, 체력 100에서 시작, 체력 0인 쪽이 패배.
- 18초 이후 이동·유도 속도 증가. 이름은 전투 계산에 사용하지 않음.
- 1배/2배속, 일시정지, 같은 시드 재생, 새로운 시드 재경기.
- 대결 이름과 32비트 난수 시드를 URL에 포함해 공유. 같은 링크는 동일한 시뮬레이션을 재현. 서버 다중 접속 대전이 아닌 관전형 게임.
- 탭이 숨겨지면 시뮬레이션 정지. 모션 감소 설정에서는 공의 잔상·광택 생략.
- 현재 방문의 최근 결과 최대 4개를 메모리 표시. 새로고침 시 삭제.

## 검증

- typecheck, lint, build 통과.
- 테스트 31개 통과, PostgreSQL 전용 테스트 1개는 별도 실행으로 생략.
- 고정 시드 결과 재현, 종료 후 불변, 벽 튕김, 100개 시드 모두 종료(최장 약 26초), 양쪽 승리 확인.
- 기존 서비스 E2E 통과. 신규 `npm run test:game`: 실제 경기 종료, 중지/재개, 2배속, 링크 복사/재접속 후 승자 재현, 빈 입력 검증, 360px 가로 넘침 없음, JS 오류 0.
- 광고·분석·리더보드·대학별 공식 전체 학과 DB는 포함하지 않음. 인기도와 광고 수익은 아직 검증되지 않음.

배포 완료 여부는 Render에서 별도로 확인. 스크린샷은 로컬 테스트판.
