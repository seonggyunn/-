# 인수인계 — SMB 온라인 운영 플랫폼

## 위치와 실행
저장소: `/workspace/-`, 애플리케이션: `/workspace/-/platform`.
기존 한칸데이터 소개·샘플·Python/GAS 영업 도구는 유지했다. 이번 새 플랫폼은 Next.js16·React19·TypeScript·Tailwind·Zod이며 Node24에서 실행한다.

```bash
cd /workspace/-/platform
npm ci
npm run db:migrate
ADMIN_EMAIL=본인이메일 npm run admin:create
npm run dev
```

이미 현재 클라우드 로컬에 유성균 님의 관리자 계정을 생성하고 로그인·로그아웃을 확인했다. 초기 자격증명은 `.data/initial-admin.json`에 비공개로 있다. Gmail 비밀번호와 별개이며 채팅·Git에 공개하지 않는다. 현재 실제 운영 DB의 신청0건·MRR0원이다. 로컬 production 서버도 시작했지만 이 주소를 공개 운영 URL로 제공하지 않는다.

## 검증된 기능
공개페이지10개, 실제진단신청저장, 관리자세션/역할, 조직별CRM·고객·업무, 상태전이, 진단기록, 변경승인·철회, 수동증빙·결과재확인, 동의와불변이력, 계약/MRR, 월간·기한·후속업무, 알림outbox, 비공개증빙, 한글PDF·보고서버전, AI없는편집템플릿을구현했다.

## 테스트와 빌드
- SQLite 단위/통합25개 통과. PostgreSQL전용진입점1개는기본명령에서건너뛰고별도로실행했다.
- 실제 PostgreSQL17검사5개 통과. 테넌트격리·RLS·익명접근거부·업무·불변이력포함.
- typecheck, lint, production build통과.
- 실제 Chromium에서공개10경로·모바일·신청저장·로그인·진단·비공개PDF다운로드통과,JS오류0.
- Git소스기반Docker빌드와컨테이너로그인/신청/보고서/한글PDF/재시작보존통과. 임시검증컨테이너는제거했다.
- production의존성audit취약점0(검사시점). 실제외부메일은발송하지않았다.

세부명령·발견후수정한문제·화면은 TEST_REPORT.md에있다.

## 데이터와 권한
로컬 SQLite 대안으로 자격증명 없이 실행된다. 운영 Supabase/PostgreSQL을 연결할 수 있는22테이블과마이그레이션이있고서버조직필터/RLS/직접REST접근차단을적용한다. 실제Supabase프로젝트를검증한것은아니다. 세션은HttpOnly·운영Secure, scrypt와토큰해시저장,보호초기계정발급을사용한다. 승인증빙없이외부변경을성공으로기록하지않는다.

## 자동화와 수동 경계
신청후업무·동의·알림대기생성,완료후보고서/PDF/알림/후속업무,월계약점검업무,기한초과알림은DB기반으로동작한다. worker를운영스케줄러로실행해야지속처리된다. 수동검수·고객권한확인·공식플랫폼작업·수금은별도다. 알림키없으면미발송미리보기이며AI키없으면템플릿이다.

## 배포·외부 연결 상태
**공개 운영 URL: 없음.** 현재호스팅/도메인·Supabase·메일·AI/GBP자격증명이없다. Docker 로컬 검증을 공개서비스배포라고 주장하지 않는다. 실제메일수신·프로필수정·결제수금은미검증이다.

남은작업순서: 운영호스팅/HTTPS·지속볼륨→운영DB와복구확인→실메일계정테스트→고객위임/승인/개인정보/정산검토→공식플랫폼API승인및별도구현→고객포털·MFA·악성파일검사·확장큐.

유료인프라·도메인·구독을구입하지않았다. 배포절차는 DEPLOYMENT.md,운영은 OPERATIONS.md,접근제어와보관은 SECURITY.md,모듈별상태는 STATUS.md에기록했다.
